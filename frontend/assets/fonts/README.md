# Local fonts

These unmodified Latin webfonts match the supplied design reference. They are served from this application, with no runtime request to Google Fonts.

- Big Shoulders Display, weights 600 to 900. Copyright 2019 The Big Shoulders Project Authors. See `big-shoulders-OFL.txt`.
- IBM Plex Sans, weights 400 to 600, and IBM Plex Mono, weights 400 and 600. Copyright 2017 IBM Corp. See `ibm-plex-OFL.txt`.

The source font stylesheet was `https://fonts.googleapis.com/css2?family=Big+Shoulders+Display:wght@600;800;900&family=IBM+Plex+Mono:wght@400;600&family=IBM+Plex+Sans:wght@400;500;600&display=swap`, as loaded by the reference site. The font files came from the `fonts.gstatic.com` URLs in that stylesheet.
